# Web-Controlled 3D Printing Filament Dryer

A Wi-Fi-enabled filament dryer built by upcycling spare 3D printer hardware and an ESP32.

## Hardware
* **Microcontroller:** ESP32 Dev Kit V1
* **Heating & Airflow:** Repurposed Creality Ender 3 V2 Neo heatsink and cooling fan
* **Temperature Sensor:** NTC Thermistor
* **Switching:** Tolako 5V Relay Module
